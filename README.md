# KaKeBo
<!-- 旧概要: 日々の支出を10秒で記録し、月末に迷わず振り返れるようにするiOS26対応の家計簿アプリ -->
日々の支出を10秒で記録し、月末に迷わず振り返れるようにするiOS26対応の家計簿アプリ

## 機能まとめ
- 支出/収入の登録（カテゴリ・メモ・タグ）
- 月次サマリー、カテゴリ別ドーナツグラフ、日別推移グラフでの可視化
- 年間レポートやカテゴリ推移、CSVエクスポートでの振り返り
- よく使う取引（テンプレート）の登録・呼び出し・並び替え
- リマインダー通知と、毎月自動生成されるTodoテンプレート
- 固定費テンプレートによる自動計上
- 共有家計簿（招待、同期、取引・カテゴリの共有）
- テーマカラーのカスタマイズとアプリロック
- バックアップの作成・復元

## 2.1.1 アップデート通知
- リマインダー機能にプレースホルダーの追加（プレミアムプラン）
- よくある取引の並び替え機能
- 共有家計簿でもよくある取引を利用できるように
- 2026年からログイン機能のカウントを追加
- 共有家計簿の機能その他微調整
