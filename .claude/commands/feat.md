---
description: 新機能の実装を開始する（main最新化 → feature/ブランチ作成 → 実装着手）
argument-hint: 機能名（例 "予算グラフ追加"）
---

新機能の実装を開始します。

引数: $ARGUMENTS（機能名とブランチ名、例: "予算グラフ追加"）

以下の手順を実行:

1. main ブランチの最新を取得（`git checkout main && git pull`）
2. `feature/{機能名の英語スラッグ}` ブランチを作成
3. ユーザーの指示に従って実装を開始

ブランチ名は機能名から適切な英語のケバブケースに変換してください。
機能の詳細が不明な場合は、実装前に確認してください。
