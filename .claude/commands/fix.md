description: バグ修正を開始する（main最新化 → fix/ブランチ作成 → 原因調査・修正）
argument-hint: 修正内容（例 "カレンダーの日付ズレ"）
---

バグ修正を開始します。

引数: $ARGUMENTS（修正内容、例: "カレンダーの日付ズレ"）

以下の手順を実行:

1. main ブランチの最新を取得（`git checkout main && git pull`）
2. `fix/{修正内容の英語スラッグ}` ブランチを作成
3. 問題の原因を調査し、修正を実装

ブランチ名は修正内容から適切な英語のケバブケースに変換してください。
修正内容が不明確な場合は、実装前に確認してください。
