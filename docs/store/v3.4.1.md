## このバージョンの最新情報（リリースノート）

```
バージョン3.4.1では、毎日の使い勝手を改善しました。

【新機能】

・起動時に最初に表示する画面を選べる設定を追加しました。ホーム・カレンダー・レポート・取引一覧・予算・取引追加から選べます。「取引追加」を選ぶと、アプリを開いてすぐに入力画面が立ち上がります。設定はサイドメニューの「起動時に開く画面」からいつでも変更できます。
・カレンダーの日付を色分けしました。祝日・日曜は赤、土曜は青で表示され、休みの日の出費がひと目で分かります。祝日は振替休日や国民の休日にも対応しています。

【改善】

・予算タブの「支出合計」に、予算を設定したカテゴリの支出だけを含めるようにしました。総予算と同じ基準になり、使用率や残り金額がより実態に合った表示になります。予算対象外の支出がある場合は、その金額を注記としてお知らせします。

今後ともKaKeBoをよろしくお願いいたします。ご意見・ご要望は設定画面からお寄せください。
```

## 補足メモ

- アプリ内のアップデート通知（`KaKeBo/App/UpdateNotice.swift` の `defaultHighlights` / `versionHistory`）と内容を揃えています。
- 実装の中身:
  - 起動時に開く画面: `LaunchScreenOption`（AppGroup UserDefaults キー `launch.screen`）。`RootTabView.startLaunchSequence` で適用し、ウィジェットのディープリンク起動時はそちらを優先。アップデート後の初回起動時に一度だけ選択画面（`LaunchScreenPromptGate`）を表示（新規インストールは対象外、アップデート通知が閉じた後に表示）。PR #211
  - カレンダー色分け: `CalendarMonthGrid`（日付セル）と `CalendarScreen`（曜日ヘッダー）。祝日判定は既存の `JapaneseHolidayProvider` を再利用。赤・青は opacity 0.9。PR #212 / #213
  - 予算タブ支出合計: `BudgetTabView.totalExpense` を有効な予算（金額>0 かつ停止中でない）を持つカテゴリのみに変更。除外分は注記表示。PR #214
- バージョン番号: `MARKETING_VERSION[sdk=iphoneos*]` = 3.4.1 / `CURRENT_PROJECT_VERSION` = 6→7（pbxproj）。新規ビルドのアップロードにはビルド番号のインクリメントが必須。
- **要・実機確認**:
  - 起動画面設定：各画面選択→再起動、「取引追加」でのシート自動表示、初回選択プロンプトが一度だけ出ること（アップデート通知の後に出ること）、予算ウィジェットタップ起動時は予算タブが優先されること
  - v3.4 から持ち越しの確認項目：ロック画面／ホーム画面の予算ウィジェット、カテゴリ選択（プレミアム）、iCloudバックアップがFilesアプリに見えるか（ビルド5以上）
- 輸出コンプライアンス回答は従来どおり（標準的な暗号化・フランス配信なし＝対象外）で申告予定。
- 「概要（Description）」据え置きで問題なし。プロモーションテキストは審査なしでいつでも更新可能。
