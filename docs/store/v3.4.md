## このバージョンの最新情報（リリースノート）

```
バージョン3.4では、予算の「残り」をもっと見やすくしました。

【新機能】

・予算の残額ウィジェットを追加しました。ロック画面（円形・横長・インライン）とホーム画面（小・中サイズ）に、予算の残りを表示できます。ウィジェットをタップすると予算タブがすぐに開きます。
・ウィジェットにはカテゴリを選んで残額を表示できます。全体予算の残額表示は無料、カテゴリを指定しての表示はプレミアム機能です。カテゴリ名やアイコンを変更しても自動で追従します。
・カテゴリ予算に「残り○○円」表示を追加しました。「使用額 / 予算」に加えて、あといくら使えるかがひと目で分かります。予算タブのカテゴリ、カテゴリの支出一覧、ホームの予算アラートに表示されます。予算を超えた場合は超過額を赤字でお知らせします。

今後ともKaKeBoをよろしくお願いいたします。ご意見・ご要望は設定画面からお寄せください。
```

## 補足メモ

- アプリ内のアップデート通知（`KaKeBo/App/UpdateNotice.swift` の `defaultHighlights` / `versionHistory`）と内容を揃えています。
- 実装の中身:
  - カテゴリ予算の残額表示: `BudgetTabView`（カテゴリ行のプログレスバー下＋カテゴリ支出一覧シートのサマリーバー）と `BudgetAlertCard`（ホームの予算アラート）に「残り○○円」を追加。超過時は赤字で超過額を表示。
  - 予算残額ウィジェット: `KaKeBoWidget/BudgetWidget.swift`。アクセサリ（円形/横長/インライン）＋ホーム（systemSmall/systemMedium）。カテゴリ選択は AppIntent 設定で、カテゴリ指定表示はプレミアム限定（全体予算は無料）。`kakebo://budget` ディープリンクで予算タブを開く（`AppRoute`）。
  - 月範囲の共有化: `MonthStartSettings` / `MonthStartResolver` を `Shared/` へ移動し、ウィジェットでもカスタム月開始日に基づく月範囲で集計。
  - 課金状態のキャッシュ: `PurchaseManager` が課金状態を AppGroup（`premium.purchasedCache`）にキャッシュし、状態変化時にウィジェットを更新。
- バージョン番号: `MARKETING_VERSION[sdk=iphoneos*]` = 3.4 / `CURRENT_PROJECT_VERSION` = 5→6（pbxproj）。新規ビルドのアップロードにはビルド番号のインクリメントが必須。
- **要・実機確認**: ロック画面／ホーム画面ウィジェットの追加・表示、カテゴリ選択（プレミアム）とプレミアム状態変化時のウィジェット更新、タップ時の `kakebo://budget` 遷移は実機で確認推奨（ウィジェットのプレミアム判定はキャッシュ経由）。
- 輸出コンプライアンス回答は従来どおり（標準的な暗号化・フランス配信なし＝対象外）で申告予定。
- 「概要（Description）」据え置きで問題なし。プロモーションテキストは審査なしでいつでも更新可能。
