## このバージョンの最新情報（リリースノート）

```
バージョン3.1では、ホーム画面と予算管理がより使いやすくなりました。

【新機能】

■ ホーム画面のカスタマイズ
設定画面からホームのカードを自由に並び替えできるようになりました。よく見る情報を上に配置できます。

■ 不要なカードを非表示
使わないカードはオフにしてすっきり。自分仕様のホーム画面に整えられます。

■ 予算から支出明細をすぐ確認
予算タブでカテゴリをタップすると、その月の支出明細をその場で一覧表示。気になる項目はそのまま編集もできます。

■ 予算リストの並び替え
予算が高い順・支出が多い順など、見たい順番でカテゴリを並び替えられます。

【改善】

・並び替えや表示の切り替えが、ホーム画面にすぐ反映されるようになりました。
・通知の挙動を改善しました。リマインダーを設定していないのにToDo通知が出る問題や、アプリを開くたびに予算通知が出る問題を修正しています。

今後ともKaKeBoをよろしくお願いいたします。ご意見・ご要望は設定画面からお寄せください。
```
