# KaKeBo 3.4.2 このバージョンの最新情報

バージョン3.4.2では、予算の不具合修正と毎日の使いやすさの改善を行いました。

【修正】
・削除したカテゴリの予算が総予算に残る問題を修正しました。予算を設定し直さなくても正しい合計が表示されます。
・予算の予測、ホーム画面、ウィジェット、前月の予算コピーでも、削除したカテゴリの予算を除外するようにしました。

【改善】
・固定費の支払日が土日祝の場合に、前または次の平日へ変更できるようになりました。月をまたぐ支払日の計上にも対応しています。
・月の開始日、カテゴリ、デザインの事前設定を不要にし、「最初の支出を登録する」からすぐ入力できるようにしました。
・初回の共有家計簿は名前だけで作成でき、アイコンや色は後から変更できます。
・プレミアムプランの機能比較とプラン選択画面を見やすくしました。
・設定とサイドメニューからコミュニティへの参加項目を削除しました。

今後ともKaKeBoをよろしくお願いいたします。
