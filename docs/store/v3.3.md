・iCloud自動バックアップのファイルが「ファイル」アプリの iCloud Drive に表示されない問題を修正しました。

## 補足メモ

- アプリ内のアップデート通知（`KaKeBo/App/UpdateNotice.swift` の `defaultHighlights` / `versionHistory`）と内容を揃えています。
- 実装の中身:
  - 写真添付: 個人帳簿のみ対応。実体は AppGroup 内 `Photos/` に保存（`PhotoStore`）、`Transaction`/`TransactionDTO` は `photoFilenames` を参照。写真添付はプレミアム機能（閲覧は非依存）。一覧プレビューは `TransactionRowPhotoPreview`（履歴/ホーム/カレンダー×2/予算明細）。
  - バックアップ zip 化: 外部ライブラリ不要の自前 ZIP(STORED) を `BackupArchive` に実装。写真があれば `backup.json`＋`Photos/` の zip、無ければ従来 JSON（後方互換）。
  - iCloud 可視化: `Info.plist` に `NSUbiquitousContainers`（`NSUbiquitousContainerIsDocumentScopePublic=true`）を追加。**この反映のためビルド番号を 4→5 にインクリメント済み**（必須）。
  - オンデマンド復元: `AutoBackupRestoreView`（設定・サイドメニューの「自動バックアップから復元」）。
- バージョン番号: `MARKETING_VERSION[sdk=iphoneos*]` = 3.3 / `CURRENT_PROJECT_VERSION` = 5（pbxproj）。
- **要・実機確認**: iCloudバックアップの Files 表示は、ビルド5を実機に入れてiCloudサインイン状態で「ファイル > iCloud Drive > KaKeBo > Backups」を確認（シミュレータ検証不可）。写真添付・一覧プレビュー・zipバックアップ往復はシミュレータで確認済み。
- 輸出コンプライアンス回答は従来どおり（標準的な暗号化・フランス配信なし＝対象外）で申告予定。
- 「概要（Description）」据え置きで問題なし。プロモーションテキストは審査なしでいつでも更新可能。
