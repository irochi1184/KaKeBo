## 補足メモ

- アプリ内のアップデート通知（`KaKeBo/App/UpdateNotice.swift` の `defaultHighlights` / `versionHistory`）と内容を揃えています。
- **年額の無料トライアルは App Store Connect 側の設定（サブスクリプション → 年額 → 紹介オファー(無料・1週間)）が必須**です。未設定だとアプリ内に「無料で開始」表示が出ません（[手順は会話ログ参照]）。
- 「概要（Description）」は v3.0 から大きな変更がないため据え置き（必要に応じて [v3.0.md](v3.0.md) を流用）。
- プロモーションテキストは審査なしでいつでも更新可能です。
