```
・一部の環境で、オーナーの共有家計簿が表示されなくなることがある問題を修正しました。
・アプリの再インストール後やiCloud同期の遅延時にも、共有家計簿がより確実に表示されるよう改善しました。

共有家計簿のデータはiCloud上に保存されており、表示されない場合もデータが消えているわけではありません。本アップデートで改めて表示されるようになります。

今後ともKaKeBoをよろしくお願いいたします。ご意見・ご要望は設定画面からお寄せください。
```

## 補足メモ

- アプリ内のアップデート通知（`KaKeBo/App/UpdateNotice.swift` の `defaultHighlights` / `versionHistory`）と内容を揃えています。
- 修正の中身: `SharedLedgerStore` のオーナー取得処理。①再インストール直後（ローカルキャッシュ空）に取得が一時的に空でも誤って「0件」を確定しないよう保護＋再試行を延長。②自分の private DB にある共有家計簿を `ownerUserId` 不一致で破棄していた不具合を修正（自分のゾーンのレコードは本人のものとして採用）。
- **未検証の注意**: 報告ユーザーの private DB レコードは開発者から閲覧不可のため、当該ユーザーが確実に復旧するかは配信後の確認が必要（最有力仮説に基づく修正）。困っている報告ユーザーがいるため、提出時に **Expedited Review（迅速審査）** の申請を検討。
- バージョン番号: `MARKETING_VERSION[sdk=iphoneos*]` = 3.2.1 / `CURRENT_PROJECT_VERSION` = 4（pbxproj）。
- 「概要（Description）」「プロモーション」据え置きで問題なし。プロモーションテキストは審査なしでいつでも更新可能。
