# ASO 原案 — KaKeBo（日本 App Store）

検索流入（オーガニック獲得）を増やすための App Store メタデータ最適化案。
ASC への反映は手動。**各フィールドの文字数は ASC 上で必ず実数を確認**すること（日本語は1文字=1としてカウント）。

## 基本方針
- Apple は **タイトル＋サブタイトル＋キーワード欄**をまとめて検索インデックス化する。
  → **3フィールドで同じ語を重複させない**（重複は枠の無駄）。
- 最重要キーワード「家計簿」はタイトルに必ず入れる。
- キーワード欄（100字）は**カンマ区切り・スペースなし**で詰める（スペースは1字を消費）。
- 競合の多い語（家計簿）＋ロングテール（共有/夫婦/レシート/予算）を組み合わせる。

現状: `KaKeBo - シンプル家計簿・支出管理`

**案A（推奨）**: `KaKeBo 家計簿 - 予算・共有・レシート`
**案B**: `KaKeBo 簡単家計簿 - 予算管理・支出管理`

- ブランド名 `KaKeBo` は維持しつつ、「家計簿」を前方に。
- 「予算・共有・レシート」で本アプリの差別化機能を検索語として露出。

## キーワード欄（最大100字・カンマ区切り・スペースなし）
※ タイトル/サブタイトルに入れた語（家計簿・予算・共有・夫婦・レシート・支出 等）は**ここでは省く**。

```
節約,貯金,お小遣い帳,出費,家計管理,かけいぼ,カップル,同棲,通帳,固定費,割り勘,つけ払い,ウィジェット,カレンダー,OCR,口座,kakeibo,money,budget,saving
```

- 入れ替え候補: `家計簿アプリ`（競合多いが需要大）、`ローン`、`サブスク管理`、`ボーナス`、`手書き家計簿`。
- ⚠️ ASC で必ず文字数を確認し、100字を超える場合は後方（英字）から削る。

## スクリーンショット（最初の3枚が勝負）
検索結果・プロダクトページで最初に見えるのは**1〜3枚目**。各画像に短いキャッチを載せる。

1. **1枚目（最大の訴求）**: 「1タップで、続く家計簿」＋ホーム/入力画面
2. **2枚目**: 「夫婦・カップルで共有できる」＋共有家計簿画面（差別化の核）
3. **3枚目**: 「レシート撮影で自動入力」＋OCR画面
4. 以降: 予算管理 / カレンダー / レポート / ウィジェット / テーマ

- キャッチは**短く・大きく**、1枚で1メッセージ。
- 端末は最新サイズ（6.9インチ）基準で作成済み。

## 運用メモ（実装不要・ASC上の施策）
- **プロダクトページの最適化（PPO）**: ASC の「プロダクトページの最適化」で、アイコン/スクショ/プレビューの A/B テストが可能。1枚目のキャッチ違いで CVR を比較する。
- **カスタムプロダクトページ（CPP）**: 流入元別（例: 共有招待リンク経由 / 節約広告経由）に最適化した別ページを用意できる。
- **キーワードは四半期ごとに見直し**: ランキングの動きを見て弱い語を入れ替える。
- **多言語展開（将来）**: 英語ロケールを追加すると海外オーガニックを取り込める（現状 ja のみ）。
