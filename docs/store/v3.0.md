## このバージョンの最新情報（リリースノート）

```
バージョン3.0では、予算管理が大きく進化しました。

【新機能】

■ カテゴリ別予算タブ
新しい「予算」タブが登場。カテゴリごとの予算と支出を一画面でまとめて確認できます。月ごとの予算消化状況もひと目で把握できます。

■ 予算アラート
予算の超過や使いすぎをホーム画面でいち早くお知らせ。使いすぎを未然に防げます。

■ 先月の支出から予算設定
ワンタップで先月の支出をそのまま予算に設定。ゼロから入力する手間がありません。

■ 予算のオン・オフ
カテゴリごとに予算を一時停止できます。金額はそのまま残るので、必要なときにすぐ元に戻せます。

■ カテゴリ画面から予算設定
カテゴリの追加・編集画面から、その場で今月の予算を設定できるようになりました。

■ サイドメニュー
メニューをサイドにすっきり整理。よく使う機能へ迷わずアクセスできます。

【改善】

・iCloud自動バックアップが確実に保存されるよう改善し、大切なデータをより安全に守ります。
・アップデートのお知らせ画面を刷新し、見やすくなりました。

今後ともKaKeBoをよろしくお願いいたします。ご意見・ご要望は設定画面からお寄せください。
```
