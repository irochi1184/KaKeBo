KaKeBo は、「すぐ記録できる」をテーマにした
シンプルで続けやすい家計簿アプリです。

1タップで支出を登録し、カレンダー・グラフ・予算管理・ToDo管理を通じて日々のお金を見える化。
さらに、レシート撮影による自動入力やアプリロック（Face ID / パスコード）にも対応しました。
大切な家計データは端末内に保存され、プライバシーを最優先に設計されています。

【主な機能】
□ ワンタップで記録
　- カテゴリと金額をすばやく入力。メモも添えられるからレシート要らず。
□ カテゴリ別の予算管理（NEW）
　- カテゴリごとに月の予算を設定し、支出とのバランスをひと目で確認。
　- 予算の超過や使いすぎはホーム画面でアラート。使いすぎを未然に防げます。
　- 先月の支出をワンタップでそのまま予算に設定でき、面倒な入力は不要。
　- カテゴリごとに予算のオン・オフも自由に切り替え可能。
□ レシート読み取り（OCR）
　- カメラでレシートを撮影、または写真から選ぶだけで金額を自動入力。
　- 手入力の手間を大幅に削減し、日々の記録がもっと簡単に。
□ カレンダー表示
　- 支出・収入を日ごとに確認でき、月全体のバランスをひと目で把握。
　- 日付ごとのメモ機能もあり普通のカレンダーとしても利用可能。
□ レポート・グラフ
　- カテゴリ別の内訳や日別の推移をグラフで分かりやすく可視化。
□ ToDoリスト機能
　- 「家賃」「サブスク」「電気代」などの月次タスクを自動でリマインド。
　- 支払い忘れを防ぎ、毎月の管理をスマートに。
□ ホーム画面・ロック画面ウィジェット & 通知
　- アプリを開かずに今日の支出や今月の収支をチェック。
　- 記録のし忘れもプッシュ通知でサポート。
□ アプリロック機能（セキュリティ）
　- パスコードまたはFace ID / Touch IDで大切な家計情報を保護。
　- パスコード桁数は4〜10桁の中から自由に設定可能。
□ データ管理・バックアップ
　- すべてのデータは端末内に安全に保存。オフラインでも安心してご利用いただけます。
　- 必要に応じて、お客様ご自身のiCloudへ自動バックアップ。機種変更時もかんたんに復元できます。
